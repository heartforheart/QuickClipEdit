## 📥 Download & Installation

1. Go to the **Releases** section on the right side of this repository.
2. Download the version you prefer:
   - **ClipEdit Setup (`ClipEdit.1.4.3.Setup.exe`)**: Standard Windows installer. Adds desktop and right-click shortcuts automatically.
   - **ClipEdit Portable (`ClipEdit.1.4.3.Portable.exe`)**: No installation needed. Run it directly from any folder or USB drive.
3. Open and start clipping!

## 💡 Why ClipEdit?

Have you ever saved a funny or cool gaming moment, and just wanted to share the best 10 seconds with friends on Discord or elsewhere, but:
- **Big video editors** (like Premiere or DaVinci) take minutes to start and are hard to use.
- **Discord** blocks your video because it is over the 20MB limit.
- **Other clipping apps** force you to sign in, upload your videos to the cloud, or put watermarks on your clips.
- **Re-rendering** makes your video blurry and takes forever.

**ClipEdit makes it fast and easy.**  
Open any video, pick where it starts and ends, and save it super fast at 100% original quality.

## 🚀 Free vs Pro (All in One App!)

Everyone downloads the same lightweight app. No separate downloads or re-installing required.

### 🆓 Free Mode (Included by Default)
- ⚡ **Instant Lossless Trimming**: Cut video clips in 1 click with zero quality loss and no slow re-rendering.
- 🎯 **Play from Start (`Ctrl + Space`)**: Jump playhead directly to your `IN` marker (or 0:00) anywhere on the timeline and immediately start playing.
- 📸 **1-Click Frame Capture (PRT)**: Save crystal-clear screenshot frames directly to disk and clipboard (`Ctrl+V` to Discord) via shortcut (`P` / `PRT`).
- 🛡️ **Anti-Doxxing Privacy Stripper**: Automatically strips Windows username paths, PC machine names, and metadata from all rendered clips.
- 🎨 **Subtle Watermark & Creator Tag**: Burn a semi-transparent gamer tag or Twitch channel into exported clips with custom opacity in Settings.
- 🌊 **Audio Waveforms**: Spot game highlights, screams, and gunshots visually on the timeline with boosted dynamics.
- ✂️ **Cut Middle Sections**: Cut out dead or boring parts from inside a clip (`C`, `V`, `X`) with automatic skip playback.
- 🚀 **Speed Controls**: Export clips in fast-forward or slow-motion (0.5x to 4.0x) with pitch-corrected audio.
- 🔊 **Dual Audio Controls**: Independent local preview volume and an export volume slider (0% mute up to 200% boost).
- 💬 **Discord 20MB & 10MB Modes**: Automatically fit clips under Discord limits with maximum visual crispness in 1 click.
- 🖱️ **Right-Click to Open**: Right-click any video in Windows Explorer and click **"Quick Clip with ClipEdit"**.
- 🔍 **Timeline Zoom**: Use your mouse wheel (`Ctrl + Scroll`) or zoom slider for exact frame cuts.
- 📋 **Auto-Copy to Clipboard**: Automatically copies saved clips to your Windows clipboard for instant `Ctrl + V` into Discord.
- ↩️ **Undo & Redo**: Full 30-step history (`Ctrl + Z` / `Ctrl + Shift + Z`) for markers, scissor cuts, and boundary adjustments.
- 🔄 **Built-in Auto-Updater**: Stay up-to-date with 1-click silent background update downloads directly from GitHub Releases with clear countdown notice.
- 🎬 **Plays All Formats**: Plays MP4, MKV, MOV, WEBM, AVI, WMV, FLV, M4V, and high-bitrate ShadowPlay recordings smoothly.
- 🔒 **100% Offline & Private**: Works completely on your PC. No accounts, no cloud uploads, no ads.

### 💎 Pro Mode (One-Time Lifetime Unlock)
- 🎞️ **Multi-Clip Batch Loading**: Drop and load multiple videos simultaneously in a visual clip tray with instant switching and background pre-loading.

## ⌨️ Keyboard Shortcuts

| Key | What It Does |
| :--- | :--- |
| **`Space`** | Play / Pause video |
| **`Ctrl + Space`** | **Play from Start (Jump directly to IN marker & play)** |
| **`I`** or **`[`** | Set clip start (**IN** point) |
| **`O`** or **`]`** | Set clip end (**OUT** point) |
| **`C`** | Start a cut in the middle (**Cut From**) |
| **`V`** | End the cut in the middle (**Cut To**) |
| **`X`** | Delete the cut part (**Cut & Remove**) |
| **`P`** | Take high-res snapshot (**PRT**) |
| **`Ctrl + Mouse Wheel`** | Zoom timeline in / out |
| **`←` / `→`** | Move 1 frame backward / forward |
| **`Shift + ←` / `Shift + →`** | Jump 5 seconds backward / forward |
| **`Home`** / **`End`** | Jump to **IN** / **OUT** marker |
| **`L`** or **`Shift + Space`** | Loop playback of selected region |
| **`R`** or **`Escape`** | Reset markers / cut selection |
| **`Ctrl + Z`** | Undo last change |
| **`Ctrl + Shift + Z`** | Redo last change |
| **`Ctrl + S`** or **`Enter`** | **Save & Export video or GIF** |
| **`Ctrl + O`** | Open a new video file |
| **`Ctrl + ,`** | Open Settings |
| **`M`** | Mute / Unmute sound |
