## 📥 Download & Getting Started

No complicated installation, no account needed, and no bloatware. Start clipping right away:

1. Head over to **[Releases](https://github.com/heartforheart/QuickClipEdit/releases)** on the right side of this page.
2. Download the version that fits your style:
   - **ClipEdit Setup (`ClipEdit.1.5.0.Setup.exe`)**: *Recommended!* Quick installer. Adds desktop icons and a 1-click **"Quick Clip with ClipEdit"** right-click menu to Windows Explorer.
   - **ClipEdit Portable (`ClipEdit.1.5.0.Portable.exe`)**: 100% standalone. No installation needed: run it straight from your Downloads folder or any USB thumb drive.
3. Drag and drop any gameplay recording into ClipEdit, tap **`I`** (Start), tap **`O`** (End), and hit **`Enter`** (Save). Done!

## ⌨️ Keyboard Shortcuts (Clip Like a Pro)

You can edit, add effects, and export an entire clip completely from your keyboard without touching your mouse:

| Shortcut | What It Does | Beginner Tip |
| :--- | :--- | :--- |
| **`Space`** | **Play / Pause** | Start or stop playing the video. |
| **`Ctrl + Space`** | **Play from Start** | Jump directly to your start marker and hear your clip from the beginning. |
| **`I`** or **`[`** | **Set Start (IN)** | Sets where your clip begins. |
| **`O`** or **`]`** | **Set End (OUT)** | Sets where your clip ends. |
| **`Enter`** or **`Ctrl + E`** | **Save & Export** | Opens the export window: tap Enter again to save right away! |
| **`P`** or **`PrintScreen`** | **Take Screenshot** | Saves a crystal-clear photo frame & copies it to your clipboard. |
| **`B`** | **Open File Explorer** | Opens the built-in browser to view your folders and clips. |
| **`K`** *(or `Shift + K`)* | **Set VFX Section** | Tap `K` to start a visual effect, move playhead, tap `K` to finish! |
| **`1` - `9`** | **Instant VFX Presets** | With a VFX section selected, tap a number to choose your effect *(see table below)*. |
| **`Alt + A`** | **Audio-Only Mode** | Toggle between exporting full video or just an MP3 soundbite. |
| **`C`** | **Cut Start (Middle)** | Marks where to start cutting out a boring middle part. |
| **`V`** | **Cut End (Middle)** | Marks where the middle cut ends. |
| **`X`** | **Delete Middle Cut** | Deletes the cut section between `C` and `V` like magic. |
| **`Delete`** / **`Backspace`** | **Clear Selection** | Clears your selected VFX effect or middle cut marker. |
| **`←` / `→`** | **Step 1 Frame** | Move frame-by-frame forward or backward for surgical timing. |
| **`Shift + ←` / `→`** | **Jump Backward / Forward** | Quickly skip backwards or forwards through the video. |
| **`Home`** / **`End`** | **Jump to Start / End** | Teleports the playhead straight to your `IN` or `OUT` marker. |
| **`Ctrl + Mouse Wheel`** | **Zoom Timeline** | Zoom in for super close cuts (`Ctrl + 0` to reset). |
| **`L`** | **Loop Playback** | Replays your selected clip on repeat to make sure it flows cleanly. |
| **`R`** or **`Escape`** | **Reset Everything** | Resets all markers back to the full video length. |
| **`M`** | **Mute / Unmute** | Turns audio preview sound on or off. |
| **`↑` / `↓`** | **Next / Prev Clip** | Quickly switch between loaded videos (in Pro multi-clip mode). |
| **`Ctrl + Z`** | **Undo** | Made a mistake? Press this to go back a step. |
| **`Ctrl + Shift + Z`** / **`Ctrl + Y`** | **Redo** | Re-applies your last undone action. |
| **`Ctrl + O`** | **Open Video** | Choose a new video file from your computer. |
| **`Ctrl + ,`** | **Settings** | Opens the settings menu (watermark, theme, folders). |
